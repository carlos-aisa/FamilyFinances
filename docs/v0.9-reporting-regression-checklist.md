# Reporting 0.9 Regression Checklist

## Scope
- Application reporting handlers (`GetMonthlySummary`, `GetEconomicState`, `GetStateEvolution`, chart/insight handlers)
- API reporting endpoints (`/api/v1/reports/*`)
- Web reporting pages/components (`/reports/*`)

## Critical Gates (Release Blocking)
1. API integration reporting suite passes:
   - `dotnet test tests/FamilyFinances.Api.IntegrationTests/FamilyFinances.Api.IntegrationTests.csproj --configuration Release --filter "FullyQualifiedName~Reporting"`
2. Web reporting component suite passes:
   - `dotnet test tests/FamilyFinances.Web.Tests/FamilyFinances.Web.Tests.csproj --configuration Release --filter "FullyQualifiedName~Reports"`
3. Application reporting suite passes:
   - `dotnet test tests/FamilyFinances.Application.Tests/FamilyFinances.Application.Tests.csproj --configuration Release --filter "FullyQualifiedName~Reporting"`

## Functional Verification
1. `Economic State`:
   - Snapshot KPIs load for default as-of date.
   - Asset and Income evolution tabs load annual and month-focused charts.
2. `Period Summary`:
   - Filters (`from/to/account/payee`) affect KPIs consistently.
   - Month-focused chart loads for selected account.
3. `Account Totals` and `Account Group Totals`:
   - Period totals and state-evolution tabs load without errors.
   - Composition and evolution charts render with valid percentages.

## Export Verification
1. CSV exports are available on table-based report views.
2. CSV payload reflects active filters and visible numeric formatting.
3. Chart-enabled cards expose `Export` (PNG download) and download current chart state.

## UX, Accessibility, and Responsiveness
1. Report filter controls include explicit accessible labels.
2. Chart canvases expose `role="img"` + keyboard focus (`tabindex="0"`).
3. Key report layouts keep responsive grid behavior (`col-12`, `col-md-*`, `col-xxl-*`).

## Performance / Reliability Checks
1. Chart rendering disables animations for deterministic/reporting-friendly redraw.
2. Components skip redundant chart re-render when payload has not changed.
3. CSV builder handles no-data output and truncates very large exports at 10,000 rows.
