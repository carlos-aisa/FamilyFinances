# v0.9.2 Economic State Notes

## Summary

Version `0.9.2` introduces a new `Economic State` report that consolidates stock and flow metrics into one explicit snapshot view.

## User-visible changes

- New report page: `/reports/economic-state`.
- New report index card: `Economic State`.
- New sidebar shortcut entry with direct navigation to the report.
- Sidebar economic-state preview now includes an explicit asset-balance as-of label.

## API additions

- New endpoint: `GET /api/v1/reports/economic-state?asOf=YYYY-MM-DD`.
- Response payload includes:
  - `AsOf`
  - `AssetsTotalCents`
  - `LiabilitiesTotalCents`
  - `NetWorthCents`
  - `IncomeTotalCents`
  - `ExpenseTotalCents`
  - `PeriodNetResultCents`

## Metric semantics

- **Stock metrics**: `Asset Balance`, `Liability Balance`, `Net Worth` (point-in-time snapshot at `AsOf`).
- **Flow metrics**: `Income`, `Expense`, `Period Net Result` (month-to-date, from first day of month to `AsOf`).
- Stock and flow metrics are shown together but remain explicitly non-equivalent metric families.

## Known limitations

- Flow period is fixed to month-to-date for the selected as-of date in this version.
- No chart package is introduced in `0.9.2`; this release focuses on KPI consolidation and navigation.
- Preference/profile persistence is unchanged; this feature is reporting-only and additive.
