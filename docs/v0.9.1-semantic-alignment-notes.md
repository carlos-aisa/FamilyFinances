# v0.9.1 Semantic Alignment Notes

## Summary

Version `0.9.1` aligns reporting metric semantics across existing report pages before chart-heavy `0.9.x` releases.

## User-visible changes

- `Monthly Evolution` summary cards now use explicit Asset semantics in Accounts scope when Asset series are available.
- `Monthly Evolution` includes an explicit stock-vs-flow disclaimer to avoid comparing non-equivalent metrics.
- `Period Summary` labels now use canonical naming:
  - `Income`
  - `Expense`
  - `Period Net Result`
  - `Transactions Count`
- Reports index copy now explicitly distinguishes flow metrics from stock metrics.

## Semantic contracts

- **Stock metrics**: Asset Balance, Liability Balance, Net Worth, balance deltas.
- **Flow metrics**: Income, Expense, Period Net Result.
- Stock and flow metrics are intentionally not directly comparable in the same way.

## Backward compatibility

- Existing report API endpoints and DTO numeric payloads remain unchanged.
- This release focuses on semantic consistency and labeling, not endpoint replacement.

## Verification highlights

- Added deterministic semantic mapping tests in Application layer.
- Added Web report tests validating semantic labels and disclaimers.
- Added API integration coverage showing stock and flow metrics can diverge by design.
