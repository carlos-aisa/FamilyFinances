# v0.9.4 Monthly Charts Notes

## Summary

Version `0.9.4` extends reporting with month-focused daily charts integrated in existing state-evolution tabs.

## User-visible changes

- `Economic State` -> `Asset Evolution` now includes:
  - focused-month selector
  - daily `Asset Total` line chart for selected month
- `Account Group Totals` -> `State Evolution` now includes:
  - focused-month selector shared across summary and chart context
  - daily `Asset Total vs Account Groups` comparison chart
- Focused-month changes trigger chart reloads without leaving the current report tab.

## API contracts

- `GET /api/v1/reports/monthly-charts/balance?year=YYYY&month=MM`
  - Response: `MonthlyBalanceChartDto`
  - Contains ordered day points with `EndBalanceCents`.
  - Optional query `accountId=<GUID>` scopes the series to a single account (Monthly Summary account-focused evolution).
- `GET /api/v1/reports/monthly-charts/group-evolution?year=YYYY&month=MM`
  - Response: `MonthlyBalanceVsGroupsChartDto`
  - Contains one `asset-total` series and one series per account group.
  - Legacy alias remains available: `GET /api/v1/reports/monthly-charts/balance-vs-groups?year=YYYY&month=MM`.

## Semantics

- Day buckets are deterministic and complete (`1..daysInMonth`).
- No-activity days use carry-forward end balances.
- Compared series are aligned to identical day buckets.
- Group series exclude liability accounts from aggregation, consistent with existing annual group evolution semantics.

## Validation scope

- Application tests cover day ordering, carry-forward, and series alignment helpers.
- API integration tests cover:
  - success cases
  - invalid query inputs
  - no-data month behavior
- Web tests cover focused-month selection and monthly chart refresh in integrated tabs.
