# FamilyFinances Portfolio Showcase

This release is a presentation-focused snapshot intended to make the project easier to evaluate by engineering managers and recruiters.

## Highlights

- Product engineering signal: clear architecture narrative, stack transparency, and quality gates visible from the repository landing page.
- Architecture ownership: modular monolith boundaries (`Domain`, `Application`, `Infrastructure`, `Api`, `Web`) presented as a deliberate design choice.
- Delivery discipline: CI quality, dependency review, and CodeQL surfaced as first-class trust indicators.
- Testing posture: unit, integration, and web test strategy highlighted as part of the default project workflow.
- Security and governance maturity: formal `SECURITY.md`, contribution policy, issue templates, and PR template aligned for team collaboration.
- Release operations readiness: categorized release notes and synchronized label taxonomy for consistent changelog generation.
- Distribution credibility: Windows installer pipeline and release assets documented for reproducible delivery.
- Open-source readiness: formal MIT license and repository policies in place for external contributors.
