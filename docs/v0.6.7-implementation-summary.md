# FamilyFinances v0.6.7 - Windows ZIP Distribution

**Release Date:** February 1, 2026  
**Focus:** Windows standalone distribution for non-technical users

## Summary

Version 0.6.7 delivers a self-contained Windows ZIP distribution that enables non-technical users to run FamilyFinances without installing .NET or any dependencies. This is strictly a packaging and delivery release with no new product features.

## What's New

### Windows Distribution Package

- **Self-contained executables** for both API and Web (win-x64)
- **Zero installation required** - includes .NET runtime
- **Portable data and logs** - all files stay in the distribution folder
- **Simple startup** - double-click `Start FamilyFinances.bat`
- **Clean shutdown** - double-click `Stop FamilyFinances.bat`
- **User-friendly README** with troubleshooting guide

### Distribution Structure

```
FamilyFinances-v0.6.7-win-x64/
  ├── Start FamilyFinances.bat     # Launcher
  ├── Stop FamilyFinances.bat      # Shutdown
  ├── README.txt                   # End-user guide
  ├── data/                        # SQLite database (portable)
  ├── logs/                        # Application logs
  ├── api/                         # API binaries
  │   ├── FamilyFinances.Api.exe
  │   └── appsettings.Production.json
  └── web/                         # Web binaries
      ├── FamilyFinances.Web.exe
      └── appsettings.Production.json
```

### Build Infrastructure

- **PowerShell build script** (`build-windows-dist.ps1`) for local builds
- **GitHub Actions workflow** automatically builds and publishes ZIP on:
  - Pushes to `main` or `develop` branches
  - Version tags (e.g., `v0.6.7`)
- **Automated verification** ensures all required files are present
- **GitHub Releases** automatically created for version tags

### Configuration

- **Production appsettings** for both API and Web:
  - Database: `../data/familyfinances.db` (portable)
  - Logs: `../logs/api-YYYYMMDD.log` (daily rotation, 30-day retention)
  - Fixed ports: API on `5084`, Web on `5019`
  - HTTP-only (local access only)

### Start Script Features

`Start FamilyFinances.bat`:
1. Creates `data/` and `logs/` folders if missing
2. Checks if processes are already running (prevents duplicates)
3. Starts API in minimized window
4. Polls API health endpoint with 30-second timeout
5. Starts Web in minimized window
6. Opens browser automatically to `http://localhost:5019`
7. Provides helpful error messages with log file references
8. Saves PIDs for clean shutdown

### Stop Script Features

`Stop FamilyFinances.bat`:
1. Cleanly terminates Web process
2. Cleanly terminates API process
3. Cleans up PID files
4. Provides confirmation messages

## Technical Details

### Publish Settings

Both API and Web use:
- Runtime: `win-x64`
- Self-contained: `true`
- Trimmed: `false` (safer, ensures compatibility)
- Single file: `false` (better compatibility with reflection and plugins)

### Architecture Preserved

- API and Web remain **separate processes**
- Web consumes API as external client
- SQLite persistence
- Identity + JWT authentication
- Serilog structured logging

No architectural changes - strictly packaging and delivery.

## Known Issues / Limitations

- **Windows only** - macOS and Linux distributions not included
- **HTTP only** - no HTTPS (local use only, by design)
- **Fixed ports** - ports 5084 and 5019 not configurable (future enhancement)
- **Default JWT key** - should be changed for production deployments
- **No auto-update** - manual download and extraction required

## Deployment Notes

### For End Users

1. Download `FamilyFinances-v0.6.7-win-x64.zip` from GitHub Releases
2. Extract to a folder (e.g., `C:\FamilyFinances`)
3. Double-click `Start FamilyFinances.bat`
4. Browser opens automatically to `http://localhost:5019`

### For Developers

**Local Build:**
```powershell
.\build-windows-dist.ps1
```

**Create Release:**
```bash
git tag v0.6.7
git push origin v0.6.7
```

GitHub Actions will automatically:
- Build the distribution
- Run all tests
- Create ZIP archive
- Upload to GitHub Releases
