# v0.9.8 UI Hardcode Normalization Notes

## Summary
This change is behavior-neutral and focuses on presentation governance hardening:
- canonical token registry creation,
- shared style/token ownership cleanup,
- chart semantic palette centralization,
- inline style literal reduction with controlled dynamic custom-property exceptions,
- anti-hardcode regression guardrails.

## User Impact
- No expected workflow or business logic changes.
- Visual output is aligned with previously approved UI baseline.

## Developer Impact
- New canonical token file: `src/FamilyFinances.Web/wwwroot/css/ui-tokens.css`.
- Chart color semantics now resolve via `ChartSemanticPalette`.
- `reportCharts.js` now resolves fallback theme and pie/bar rendering constants from token maps.
- New documentation: `docs/frontend-token-governance.md`.
