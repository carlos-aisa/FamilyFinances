# v0.9.6 Reporting Closeout Notes

## Validated Scope
- Added CSV export actions for table-based reporting views with active filter context.
- Added chart image (`PNG`) export actions for chart-enabled reporting cards.
- Improved report accessibility baseline:
  - explicit labels in key controls
  - keyboard-focusable chart surfaces with semantic roles
- Added responsive refinements for export/action layouts on small screens.
- Added reporting gate in CI (`reporting-release-gate`) and made distribution depend on it.
- Added targeted tests for:
  - CSV payload consistency against on-screen values
  - chart export action wiring
  - responsive-report markup regressions

## Performance / Reliability Hardening
- Disabled chart animation for reporting charts to reduce redraw overhead.
- Avoided redundant chart JS re-renders by checking payload signature.
- Added CSV output safeguards:
  - deterministic no-data output
  - truncation guard at 10,000 rows

## Verification Executed
- `dotnet build --configuration Release`
- `dotnet test --configuration Release --no-build`
- `dotnet test tests/FamilyFinances.Web.Tests/FamilyFinances.Web.Tests.csproj --configuration Release --no-build`

## Known Limitations
- CSV exports currently include UI-formatted numeric strings (localized), not raw cents columns.
- PNG export depends on browser support for `canvas.toBlob`.
- Responsive verification is covered at component markup level (no browser E2E viewport matrix in CI yet).
